# Batoi Press 2.3.1

This patch fixes password recovery and improves update-check diagnostics. Default theme 3.2.0 and bundled UIF 3.0.0 are unchanged. No content migration is required.

Existing installations: the 2.3.0 updater does not replace files under `radpress/bin/`. After verifying the signed package, separately copy `radpress/bin/reset-admin-password.php` from the 2.3.1 ZIP to the same private installation path to receive the CLI recovery fix. Fresh installations include the corrected utility. Do not change `config/users.json` or reset a working password merely to install this file.

## Fixes

- Persist the new password when using the CLI reset utility; the previous reference loop could report success while leaving the stored hash unchanged. Unrelated account fields are preserved.
- Distinguish an older stable manifest from an installation matching the stable version; do not suggest downgrading.
- Reject malformed manifest versions and return safe diagnostics for recoverable transport exceptions.
- Remove the deprecated PHP 8.5 cURL-close call without changing TLS or signature verification.
- Document custom-theme integration and current signed-update behavior.

## Verification

Regression coverage includes CLI password-reset persistence and rejection without mutation, update comparison/error rendering, and custom-theme header/CSS/JavaScript UTF-8 saves, including `innerHTML`, snapshots, and subdirectory redirects. The suite contains 36 PHP test scripts.

## Open environment acceptance

The local MAMP PHP 8.5.2 FastCGI update check still encounters a native macOS Objective-C fork-safety abort during DNS resolution. Both cURL and a temporary HTTPS-stream experiment reproduced the crash; the unsuccessful workaround was removed. CLI signed checks succeed. This release does not claim to repair that shared-server runtime problem, and does not disable fork safety, TLS, or package signatures.

The team's rejected XML sample, affected Windows/macOS package reports, and affected-live-host template-save logs remain required for those acceptance checks. Native XML support does not imply arbitrary XML or remote-media import. Publishing this release on GitHub does not itself deploy the production Batoi distribution endpoint.
