# Batoi Press 4.0.8

Batoi Press negotiates gzip for eligible public text responses and gives public assets a one-hour default cache lifetime. Native carousels prioritize their initial image and defer inactive slides. When PHP GD supports WebP, published pages can prepare responsive copies of existing local images for later requests.

The configured site URL supplies canonical links, matching www or non-www redirects, and the sitemap location in robots.txt. The configured homepage redirects to the site root. Missing search metadata is derived from existing content and site settings.

The updater retains existing content, configuration, hosting rules and custom themes. Explicit asset cache settings, authored search metadata and custom theme tags remain authoritative. See the [installation guide](../installation.md) for hosting behavior and settings.
