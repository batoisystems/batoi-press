# Batoi Press 4.2.0

- **Share to Social in Workspace** opens a draft from a saved public page or post. Press supplies the public URL, a suggested caption and an available JPEG. An authorized Workspace user chooses a destination and confirms publishing.
- The Workspace pilot supports Facebook Pages and Instagram professional accounts through Meta OAuth. A Press installation administrator enables the handoff by setting `BATOI_PRESS_SOCIAL_WORKSPACE_URL` to the Workspace Social Publishing route.
- Standalone Social Publishing and its token setup remain available independently.

Install the signed 4.2.0 package through **Admin → Updates**. See the [Social Publishing guide](../social-publishing.md) for configuration.
