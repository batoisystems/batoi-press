# Batoi Press 4.3.0

- Site owners can save the Workspace Social Publishing URL in **Admin → Social Publishing**. The editor carries the verified Press Studio site identifier through to the Workspace share draft.
- Existing environment-based handoff settings continue to work until the owner saves a setting. Saving a blank URL disables the handoff.
- Standalone social publishing with provider tokens remains available.

Install the signed 4.3.0 package through **Admin → Updates**. See the [Social Publishing guide](../social-publishing.md) for setup.
