# Batoi Press 4.0.1

Maintenance and installation-testing release in the 4.0 line, published at the
project owner's request. This does not declare the wider 5.0 roadmap complete.
Previously published versioned archives remain unchanged.

## Changes

- Page/post private encrypted recovery, explicit pending/saved states, source
  conflict comparison, pre-submit preservation and links from failed saves.
- Integrated image selection/upload, meaningful/decorative alt choice, captions,
  cursor insertion and keyboard focus return. Corrected editor grid overflow.
- Local font management, timezone/date-format controls, gallery and theme
  presentation compatibility fixes, and metadata-only content reads.
- Upgrade compatibility preserves customized bundled themes, records installed
  provenance, and supports base-URL repair within the backup/rollback boundary.
- Preview default-off Stripe Checkout store, integer product pricing, stock
  reservations, recoverable orders, signed callbacks and merchant administration.
- Preview portable UIF Theme Kit and explicit owner-only MCP/API theme drafts.
  Drafts cannot install or activate themes. Added plugin authoring/signing tooling.

## Upgrade and testing

PHP 8.3 or later is required for web and CLI. Back up the full installation,
including business data and the encryption key, before applying the signed ZIP.
The runtime update backup is not a complete business-data backup. Preserve custom
themes and hosting configuration; use the documented [recovery workflow](../update-recovery.md)
when the installed updater predates automatic theme preservation.

Existing publishing and signed-package enforcement remain enabled. Commerce is
off by default and must undergo real Stripe merchant sandbox acceptance before
use. Recovery and theme drafts need host encryption support. No merchant secrets
or AI provider credentials are supplied in the release.

Local regression, syntax, commerce concurrency/recovery, generated-theme package,
MCP/API permission and editor browser checks have passed. Real hosting/merchant
tests, named Claude/Gemini/ChatGPT acceptance, complete WCAG/assistive-technology
review, unified theme activation proposals and the remaining 5.0 release gates
are still open. See the feature guides for exact limits; publication is not a
security or accessibility certification.
