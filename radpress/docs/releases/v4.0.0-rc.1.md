# Batoi Press 4.0.0-rc.1

Major-upgrade testing candidate. This is a GitHub prerelease, not the stable
update channel. Stable remains 3.2.4 while installation and external-service
acceptance continue.

## Changes

- Compact branded admin/public styling, mobile navigation with keyboard focus
  recovery, permission-aware dashboard actions and recent content in the first
  viewport. Email and content-block presentation are editable theme partials.
- Optional owner-controlled Plugins and Forms modules. Signed native packages
  support inspection, compatibility/capability checks, settings, activation,
  upgrade, rollback and recovery. Native PHP remains trusted executable code.
- Plugin API 1.0.0 adds governed content proposals, authenticated media/audit
  services, configured form submission, sanitized page blocks and protected
  extension admin pages. Content proposals still require human approval.
- Declarative accessible forms, draft preview, contact-draft conversion,
  private redacted submissions and retention. Encrypted queued email/webhooks
  use atomic acceptance, stable identities, bounded retries and manual/optional
  CLI processing. Receivers must deduplicate at-least-once delivery.
- Theme contract 1.0.0 validates version bounds, palette defaults and required
  email/block partials while retaining legacy manifest defaults.
- Security fixes include atomic quotas and one-use MFA recovery, account-bound
  step-up limits, parser-based HTML sanitization, signature/checksum verification
  at update Apply, bounded ZIP extraction and formula-safe audit exports.
- Optional OAuth verification adds bounded provider introspection and stricter
  token/JWKS trust handling. Local login and personal-token recovery remain
  available when external verification is unavailable.

## Compatibility and installation testing

**PHP 8.3 or later is required**, including both web PHP and CLI PHP. Core local
publishing needs native JSON, sessions, hashing, filters, password hashing,
secure randomness, reliable locks and atomic rename. No database or specialized
PHP library is required for a simple site. DOM, Fileinfo, ZIP, Sodium/OpenSSL,
cURL, GD and mbstring enable their related optional features; see
[installation guidance](../installation.md).

Back up the installation and apply the signed `batoi-press-4.0.0-rc.1.zip` through
Admin → Updates. The package preserves existing content, configuration except
release-version metadata, site modules and hosting rules. Review custom/default
theme edits before updating; shipped default-theme files are updated. Older
1.8.0 installations require the documented [updater recovery](../update-recovery.md).
Retain the pre-update backup and previous runtime for rollback, including private
plugin state and encryption keys.

Custom forms/webhooks start disabled. No external service is enabled or credential
provisioned by installation. Review [plugin SDK and recovery](../plugins.md)
before activating native packages or delivery actions.

## Verification and remaining acceptance

Local verification passed all 59 PHP and one JavaScript regression entrypoints,
changed-file PHP lint, smoke, updater, static export and focused PHP 8.3/8.5
checks. Authenticated isolated Chrome review covered root/subdirectory admin,
dashboard/editor/plugins/forms and 390px mobile navigation. Release artifacts
are built from the exact committed source and verified against the existing
offline signing public key. Test harnesses and private state are excluded.

This candidate does not certify the full hosting matrix, genuinely absent
compiled extensions, actual low-disk/abrupt-process recovery, the Testing Team's
failed host/ZIP, complete accessibility/performance acceptance, real inbox
rendering, Batoi Flow delivery or hosted OAuth client/provider behavior. The
repository source security review excludes manual third-party vendor/UIF audit;
the current locked Composer dependency advisory check reported no known issues.
Complete these gates before promoting a stable 4.0.0 release.
