# Batoi Press 3.0.0

Stable release, explicitly approved by the maintainer on 19 September 2026. Review the breaking integration changes and back up each installation before updating. Stable release status does not certify the pending external OAuth/client integrations listed below.

## Changes

- Account-bound machine connections with current role/scope checks, rotation, revocation and explicit OAuth local-account links.
- Governed content proposals, escaped review diffs, password/MFA approval, conflict detection, child-route impact review and recoverable multi-file writes.
- Expanded editorial, menu, widget, public-settings, media and bounded audit tools through JSON API and MCP.
- MCP wire-format and HTTP authentication-status corrections; protected private integration storage and release-package exclusions.

## Breaking integration changes

Machine publication and public-impact edits now return pending proposals rather than publishing immediately. Clients must inspect proposal status and have an authorized administrator review the exact change in Press. Do not treat a successful preparation response as publication.

Connections require an active eligible local account and current effective grants. OAuth additionally requires explicit issuer/subject/client binding; email matching does not grant access. Review legacy credentials in Connections, replace them with account-bound credentials and revoke old credentials after verification. Authors/viewers do not receive machine access in this release.

## Installation and rollback

Back up the complete installation, including content, configuration and private runtime state. Test on a non-production copy first. Upload the signed release ZIP in Admin → Updates, stage it, review diagnostics and apply. The built-in updater preserves installation data and records a code backup; do not unzip the complete archive over an existing installation because starter configuration/content are also present for fresh installs. No SQL migration is required.

Verify login, existing public pages, Connections and proposal review after updating. For rollback use the update backup and the documented recovery procedure; preserve newer content and credential revocations rather than restoring stale runtime state indiscriminately.

## Acceptance status

The prior full 45-script PHP suite and local HTTPS checks passed for draft creation, password rejection, browser publication, rejection preserving the exact revision, approved content/slug changes and revoked-token refusal. MCP SDK execution and Claude Code connection-health checks passed. These are not complete product-client certification.
