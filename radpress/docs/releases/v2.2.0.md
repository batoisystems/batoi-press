# Batoi Press 2.2.0

Batoi Press 2.2.0 addresses the September 2026 Batoi Test Team backlog across content editing, product catalogues, integrations, appearance, imports, and deployment compatibility.

## Highlights

- Adds sortable page content blocks and scoped page CSS/JavaScript.
- Adds product management with public shop and product pages.
- Adds hierarchical posts and configurable blog pagination.
- Adds targeted widgets for posts, tags, galleries, activity, and configured subscription content.
- Adds Mailgun/server mail, contact delivery, reCAPTCHA, analytics, appearance controls, alternate dark logos, fonts, and footer copy.
- Adds conflict-safe Batoi Press XML import for pages, posts, and media.
- Preserves advanced HTML in explicit source mode.
- Encodes theme-template submissions to reduce shared-hosting WAF false positives; hosting verification is still required.
- Normalizes update paths across Windows, macOS, and Unix hosting.

## Review corrections

- Keeps body-only API edits synchronized with the default HTML block; complex pages require explicit block edits.
- Enforces page/block size limits and rejects alternate script/style closing-tag syntax.
- Registers CSP hashes only for explicitly authorized inline scripts.
- Preserves contact rate limits after successful sends and returns visitors to the configured contact page path.
- Rejects duplicate product creation without overwriting the existing product.
- Renders dynamic widgets in page blocks and preserves nested post links in homepage and archive output.
- Resolves imported parents before children and skips unresolved hierarchies.

## Scope and remaining acceptance checks

- Products provide catalogue and inventory editing, not checkout, payments, or order processing.
- Subscribe and Image Gallery widgets use administrator-supplied HTML; there is no subscriber database or mailing-list delivery workflow.
- XML import accepts the Batoi Press format; it is not a general WordPress importer.
- Automatic third-party theme conversion continues through the existing Platform Build handoff.
- Real Mailgun/reCAPTCHA delivery, authenticated browser workflows, and signed updates on Windows/macOS/cPanel remain deployment acceptance checks.
