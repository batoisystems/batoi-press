# Batoi Press 4.1.0

## Data Collections

- Create JSON-backed collections from **Admin → Collections**. Define typed fields and edit, search, filter, archive, or paste records in bulk.
- Import CSV and XLSX with worksheet selection, column mapping, and a preview. Match by Record ID or a unique field to update existing records. Export to CSV or XLSX.
- Review draft changes against published data. Publish selected records, eligible records from the latest import, or the entire draft. Restore the previous publication when needed.
- Display published data through Collection blocks in cards, lists, tables, or custom theme layouts. Live pages and static exports use the same renderer.

## Page editor

- Arrange content in grid blocks, configure image galleries, and style blocks with custom classes. Post archives can display matching sidebar widgets.

## Upgrading

Install the signed 4.1.0 package through **Admin → Updates**. CSV and manual entry use the core hosting profile. Check **Hosting Health** for XLSX availability. Older published collections support selective publishing when Press can match their rows unambiguously to record IDs.
