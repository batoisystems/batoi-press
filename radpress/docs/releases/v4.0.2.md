# Batoi Press 4.0.2

## Editor toolbar

The Admin editor toolbar now occupies a row above the editor body. The previous
sticky offset covered the first lines of text on desktop. The toolbar scrolls
with the editor and stays above the writing area in focus mode. Chrome checks
covered desktop scrolling, mobile layout, rich editing and source editing.

## Upgrade

Back up the installation and apply the signed 4.0.2 ZIP through **Admin → Updates**.
PHP 8.3 or later is required. See the [4.0.1 notes](v4.0.1.md) for preview features
and the [update recovery guide](../update-recovery.md) for rollback instructions.
