# Batoi Press 4.0.3

Press now explains how to convert a static Exchange template into a native
theme. The inspection report shows where to submit the original ZIP and its
compatibility report in Batoi Build, how to verify the signed result, and
how to preview the imported theme before activation. The
[theme development guide](../theme-development.md#convert-an-exchange-template)
also describes how to port a template locally.

Back up the installation and apply the signed 4.0.3 ZIP through **Admin → Updates**.
PHP 8.3 or later is required. See [update recovery](../update-recovery.md)
for rollback instructions.
