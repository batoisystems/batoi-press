# Batoi Press 1.8.0

Batoi Press 1.8.0 closes the current testing-team follow-up with more reliable shared-hosting updates and practical homepage and theme-editing improvements.

## Highlights

- Make update checks prefer PHP cURL and fall back to verified HTTPS streams, with actionable hosting diagnostics when both transports fail.
- Diagnose HTML release pages, non-ZIP uploads, empty or incomplete archives, corrupt ZIPs, and missing ZipArchive support separately during update staging.
- Add a per-page Latest posts section with an admin-controlled limit from 1 to 12; enabling it on the configured homepage produces a dynamic newest-posts feed in normal and static output.
- Let the constrained theme editor create a missing Contact layout from safe PHP starter source for custom themes.
- Keep the mobile brand and menu button on one row and expand the opened navigation across the full header width, including nested menus.
- Preserve the pages-only homepage selector decision: posts and category archives remain content routes and can be surfaced through page content or the new Latest posts section.

## Compatibility and Safety

- Existing pages default to a hidden Latest posts section, so current output does not change until an editor enables it.
- Custom themes receive an optional `$latestPosts` page-layout variable; existing layouts remain valid without using it.
- Update transport fallbacks keep TLS peer and host verification enabled.
- Update packages retain the existing manifest and checksum contracts, including standard root archives and one-folder desktop ZIP wrappers.
- Existing LaTeX, code-block, and protected text-only editing behavior from 1.7.0 remains unchanged and covered by regression tests.

## Verification

- PHP syntax checks and the complete repository regression suite pass.
- Tests cover manifest parsing and failures, desktop ZIP wrappers, HTML/non-ZIP uploads, truncated archives, page settings, static latest-post output, and missing Contact-layout creation.
- Release packaging, manifest checksum, installable-file inventory, and runtime-state exclusions pass verification.
- The synchronized testsite is updated and reviewed at desktop and mobile widths before publication.

## Versions

- Batoi Press: 1.8.0
- Bundled Batoi Versatile theme: 2.2.0
