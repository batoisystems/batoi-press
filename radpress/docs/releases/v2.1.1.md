# Batoi Press 2.1.1

Batoi Press 2.1.1 is a focused compatibility release for remote update checks
on shared-hosting environments.

## Fixes

- Keep remote manifest checks working through PHP cURL when
  `allow_url_fopen` is disabled.
- Attempt the PHP HTTPS stream fallback only when `allow_url_fopen` is
  available.
- Provide transport-specific diagnostics for unavailable cURL, outbound HTTPS,
  DNS, and CA certificate failures.
- Add regression coverage for the cURL-first transport and guarded stream
  fallback behavior.

## Compatibility

This patch preserves the Batoi Press 2.1 content, theme, route, signed-update,
and bundled asset contracts. No migration is required.

## Versions

- Batoi Press: 2.1.1
- Bundled Batoi UIF: 3.0.0
- Bundled Batoi Versatile theme: 3.0.0
