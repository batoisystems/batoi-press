# Batoi Press 4.0.5

Release packages now declare mode `0644` for files and `0755` for directories. These defaults keep PHP entry points compatible with cPanel suPHP when the hosting account owns the files.

The installer and updater repair legacy `0777` entries in the standard application tree while retaining owner write access. The updater stages packages in private storage and checks write access to the configured runtime directories.

If an existing site returns HTTP 500 before PHP starts, correct ownership and permissions on the hosting account first. See the [installation guide](../installation.md#file-permissions).
