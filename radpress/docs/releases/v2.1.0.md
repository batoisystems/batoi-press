# Batoi Press 2.1.0

Batoi Press 2.1 upgrades the bundled interface framework and adds focused
administration improvements while preserving the 2.0 content, theme, route,
and signed-update contracts.

## Highlights

- Upgrade the bundled browser distribution to Batoi UIF 3.0.0 from the
  `batoi-uif` repository, including the CSS, IIFE, and ES module builds.
- Keep the legacy `uif.life.js`, `uif-core.css`, and `uif-core.js` public URLs
  synchronized with UIF 3.0.0 for backward compatibility.
- Add governed, non-executing theme compatibility inspection with compatible,
  repairable, convertible, and unsafe classifications before installation.
- Add a server-supported timezone selector with validation and safe handling
  for previously configured timezone values.
- Extend release verification so the UIF compatibility aliases must be present
  and match the bundled 3.0.0 assets.

## Compatibility

This is a backward-compatible update for supported 2.0 installations. Existing
content, configuration, themes, public URLs, and update trust settings remain in
place. The Press-specific `uif.js` initializer is retained and continues to call
`BatoiUIF.autoStart()`.

## Versions

- Batoi Press: 2.1.0
- Bundled Batoi UIF: 3.0.0
- Bundled Batoi Versatile theme: 3.0.0
