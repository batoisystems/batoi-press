# Batoi Press 4.0.10

- **Upgrade to Latest** in Admin Updates checks the signed stable index,
  downloads and verifies the package, and installs it. Press creates a rollback
  backup and runs health checks. Manual ZIP uploads remain available.
- **View site** in the Admin navbar opens the public site in a new tab.

Install the signed 4.0.10 ZIP through **Admin → Updates** to get the new upgrade
action. See the [Updates guide](../updates.md) for hosting requirements and
manual recovery options.
